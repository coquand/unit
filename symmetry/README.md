# Symmetry in Unit

This is a working formalisation of chapters 1–8 of the book [*Symmetry*](https://github.com/UniMath/SymmetryBook) by Bezem, Buchholtz, Cagne, Dundas and Grayson. The table records what can currently be used from Unit. A chapter entry means that the indicated results check. Several chapters still have open sections and exercises. Exercise 8.4.3 is outside the requested coverage.

## Checking

From this directory run

```sh
python3 check.py --universe-tests
```

The script reads the library from the Git objects of the enclosing repository at revision `0b2e95a8dda49de0e7e50ed012c64c6e0a26862d` (on the branch `core-abstraction`; the library on `main` has since changed), so the clone must contain that revision. It stages the necessary imports in a fresh temporary directory for each entry point. By default it uses the executable reported by `cabal list-bin exe:seg` in the repository root. With the checker of `main` the three entry points (11714, 2215 and 1270 declarations, including the imported libraries) check in about 4 s, 0.5 s and 0.2 s on an Apple M4 Pro. Set `UNIT_ROOT` to use another clone containing the revision, and `UNIT_CHECKER` to select an executable. Each of the three checks must report zero failures. Declaration counts include the imported libraries.

The type theory and library come from [coquand/unit at the pinned revision](https://github.com/coquand/unit/tree/0b2e95a8dda49de0e7e50ed012c64c6e0a26862d). The reference development is the [book's Rocq formalisation](https://github.com/UniMath/SymmetryBook/tree/cdc1dc873dda4ddc0373ca8696be7a299a1ca4cf/Formalization). Only Unit sources enter the check. The book writes composition in function order. In Unit `trans p q` traverses `p` first. The book points a map by an equality from the target point to its image. Unit's `PtMap` uses the inverse equality.

## Assumptions and reuse

[All.seg](All.seg) takes univalence and the two fields of replacement (a small image in a locally small type, with its surjectivity principle). Function extensionality follows from univalence. The imported Unit libraries construct propositional truncation, set quotients, higher truncations and Eilenberg–Mac Lane spaces in this segment. In `EM.EMSpace[A]`, `K zero` is K(A,1) and `K n` is K(A,n+1). The chapter 3 circle uses this very K(ℤ,1). No propositional resizing or excluded middle is assumed. Chapter 2 treats excluded middle as a local hypothesis when proving its consequences.

§8.5 is marked “TBW” in this edition. Chapter 8's `WithCoequalizers` takes one additional construction, a small homotopy coequalizer with point and path constructors and a mapping equivalence into every target universe. This supplies arbitrary homotopy pushouts, wedges and bouquets. The group sum and bouquet construction of the free group use their pointed 1-truncations. The algebraic construction of the free group checks separately in the base segment. The ordinary group coproduct also has a construction in the base segment. A small type of derivation trees generates a congruence on terms. Replacement gives the quotient. Interpreting terms gives the universal homomorphism, and induction proves its uniqueness.

[Categories.seg](Categories.seg) and [FreeGroups.seg](FreeGroups.seg) reuse the upstream category and free-group developments in separate entry points, since the historical libraries use different records under the same names. Main dependencies are `sag/pi3-s2-postnikov`, `sag/em`, `sag/categories` and `sag/freegroup`. The replacement and truncation modules are those of this repository at the pinned revision.

| [Root bundles](chapters/CycleRootFibres.seg) | For cycles on sets in U u, the fibre of the formal root map lives in U u+. Its period condition and orbit quotient both live in U u. The classification gives an explicit equivalence between the two presentations. |

| [Yoneda](chapters/ChapterSix.seg) | The object, hom and value levels o, h and v are independent. Natural transformations from the representable live at o ∨ h ∨ v and evaluation is an equivalence to a type at v. |
| [Finite sets](chapters/FiniteSets.seg) and [torsors](chapters/TorsorDelooping.seg) | The classified objects live in a successor universe. Replacement constructs an equivalent carrier at the original level from a locally small image. |
| [Coequalizers](chapters/HomotopyCoequalizer.seg) | The optional construction selects one object at the source level. Its universal property quantifies over an independent target level. |

The command above checks the chapter proofs and the [universe tests](tests/UniverseBounds.seg). The tests require acceptance of nine well-sized declarations and rejection of nine variants that drop a successor, omit a join or instantiate a constrained theorem at unrelated levels. The [category tests](tests/CategoryBounds.seg) also require three accepted bounds and three rejections for the presheaf universe and small Rezk completion. Omitting the command-line flag checks only the proofs.

The checker at the pinned revision distinguishes a family `P : A -> U v` from a family declared at the join. Passing `\ x -> P x` lets each value use cumulativity. Another example occurs with the standard rotation in the proof of the cyclic mapping theorem. Its `isEquiv` record is constructed at the level of the finite type, so its inverse law uses `Prelude[u].sec-ret` at that level. The result can then be used at the join.

## A constructive qualification in Exercise 8.4.3

The exercise gives two subsets by proposition-valued predicates on a finite ambient set and asks for their cardinalities. With the book’s definition of finiteness, even a subtype of the singleton need not be known finite. Unit proves that a proposition P is finite if and only if P is decidable. In particular, the principle that every subset of a finite set is finite implies excluded middle. [FiniteSubsets](chapters/FiniteSubsets.seg)

For decidable membership, Unit proves the numerical inclusion–exclusion formula. The preceding equivalence of disjoint sums needs decidability of only one of the predicates and works for any ambient type. [InclusionExclusion](chapters/InclusionExclusion.seg)

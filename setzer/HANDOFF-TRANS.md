# Handoff: transitivity of ≺′ (second half of Setzer's Lemma 2.4): DONE

`OTTrans.seg`, `lt-trans` (green, 0.07 s, no postulates). See README.md,
Step 2, and the comment at the top of `OTTrans.seg`.

Correction to the earlier plan: no size bound is needed. The induction
hypotheses used are all at triples that are smaller for the lexicographic
subterm order on (x, y, z). So nested structural recursion (x, then y,
then z) is enough: when x′ is a proper subterm of x, the outer hypothesis
holds for every y′, z′. The one permuted triple, e ≺′ c ≺′ a in (3),
comes from (a, e, c) by trichotomy.

To change the dispatcher, edit `tools/gentrans.py` and run
`python3 tools/gentrans.py` (it rewrites `OTTrans.seg` after the marker
line `-- Transitivity (generated by tools/gentrans.py)`).

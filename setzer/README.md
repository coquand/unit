Choices in the transcription (stated in the comment of `OT.seg`):

1. Sums are right-nested `plus`, so a tail is again a term.
2. ≺′ is one primitive recursion computing the pair (x ≺′ y, y ≺′ x).
   The outer recursion is on x and the inner one on y. Clause (11)
   negates the direct clause of the converse pair.
3. In (4), "max{a,b} ≺′ c" is read as "a ≺′ c and b ≺′ c". This is the
   only comparison of two subterms of the same argument. The two readings
   agree where ≺′ is linear on smaller terms.

Results of the tests (tests, not proofs):

- ≺′ is a linear order on all 4200 terms of T′ of size ≤ 8, so Lemma 2.4
  holds as stated (on T′, not only on OT) as far as tested.
- Remark 2.15 (b)–(e) holds for 8 cardinals and 378 candidate b. (e) needs
  ≼ κ⁻ as printed: with ≺ κ⁻ it fails at b = κ⁻ = ψ_I 0, κ = Ω_{ψ_I0+1}.

## Step 2 (done): Lemma 2.4, ≺′ is a linear order on T′

`OTLaws.seg` (672 lines, 70 declarations of its own, checks in 0.02 s):

- `cmp2-swap`: cmp2 y x = swap (cmp2 x y), for all raw terms. The two
  computations of "y ≺′ x" agree.
- `cmp2-irr`, `lt-irr`: irreflexivity.
- `cmp2-excl`: for x ≠ y in T′, exactly one of x ≺′ y, y ≺′ x.
  Corollaries `lt-asym`, `lt-total`. T′ is needed: on raw terms
  trichotomy fails, for example for ψ_I 0 against ψ_{ψ_I 0} 0.

Method: each clause of Def. 2.3 is a truth-table lemma over Boolean
variables (`ex-cl2`, `ex-cl3`, `ex-cl5`, ...), proved by exhaustive
`split`. Each case of the main recursion instantiates one of them with
the induction hypotheses (`facts`).

`OTTrans.seg` (1090 lines, 89 declarations of its own, checks in 0.07 s):

- `lt-trans`: x, y, z in T', x ≺′ y, y ≺′ z ⟹ x ≺′ z.

Informal proof in the file comment. The points:

1. Recursion on x, then on y, then on z is enough. The hypothesis is used
   at triples (x′, y′, z′) where x′ is a proper subterm of x, or x′ = x
   and y′ is a proper subterm of y, or x′ = x, y′ = y and z′ is a proper
   subterm of z. There are no sizes and no arithmetic. The only permuted
   triple (e ≺′ c ≺′ a in clause (3)) comes from the triple (a, e, c) by
   trichotomy (`lt-rot`).
2. One lexicographic step (`lex-trans`, `by-lex`) is used three times.
   The order is lexicographic in a key and a tag: for sums (key = first
   summand), on G′ (key of ψ_π b = π for π ≠ I) and on Car′ (key of
   Ω_a = a). Views: one lemma per pair of kinds (`lex-PP`, `lex-SS`,
   `lex-ST`, `lex-OO`, ...).
3. φ: seven case lemmas `caseFFF` … `caseGGF`, generic in the G′ term,
   from (3) and from (4) in the form φ′_a b ≺′ g iff a, b ≺′ g, and
   g ≺′ φ′_c d iff g ≼′ c or g ≼′ d.
4. Fi′ (ψ_I b, I): `caseTTT` and three one-line facts.
5. The dispatcher `lt-trans` has 216 cases of constructors, with the
   index of each ψ split into I and not I. Each case is one call. It is
   generated by `tools/gentrans.py`, which rewrites the file after its
   marker line.

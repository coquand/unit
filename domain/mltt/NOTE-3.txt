3.1 Syntax

Fin n is defined by recursion on n (Fin 0 = Empty, Fin (n+1) = Opt (Fin n): none or some i),
so that an environment on n+1 variables is defined by cases on none, some i.
Terms are the indexed family Tm n of terms with n free variables:
var i, U, Pi A B, lam A M, app M N, B and M in Tm (n+1).

Renaming and substitution are one traversal over a kit (McBride): a kit
gives a family V n of values with var : V n -> Tm n, a value vz for the
new variable and a weakening wk : V n -> V (n+1).  trav s M replaces
var i by var (s i) and lifts s under a binder: lift s 0 = vz,
lift s (i+1) = wk (s i).  The renaming kit has V = Fin, vz = 0, wk = suc;
weakening of terms wk M is the traversal with i |-> i+1.  The
substitution kit has V = Tm, vz = var 0 and wk = weakening of terms.
M[N] is the traversal with 0 |-> N, i+1 |-> var i.

Contexts: Ctx 0 = 1, Ctx (n+1) = Ctx n x Tm n; lookup G i is the type of
var i, weakened to the full context.  The judgements are one family Der
indexed by the judgement forms  wf G,  G |- M : A,  G |- M = N : A, with
the rules of MIN (variables, U, Pi, lam, app, conversion; refl, sym,
trans, conversion, beta, Pi-congruence, eta (funext), the two
application congruences).

3.2 Filters (the paper's ideals, Def. 2.7)

A filter X is a predicate on types with om in X, closed under meets and
upward closed (s in X, s <= t give t in X): an ideal of compact elements
for the paper's order.  Membership is not truncated: nothing below uses
that it is a proposition, so there are no parameters.  Filters are
compared by inclusion X c= Y and equivalence X == Y (both inclusions).
prin s = { t | s <= t };  univF = prin U.

Entries.  For a relation R on types, EntS R f says that f is a function
made of entries x -> v with R x v:  EntS R om;  R x v gives
EntS R (x -> v);  EntS R f1, EntS R f2 give EntS R (f1 /\ f2).
A function f with EntS R f has no U or Pi component.

Operations.  For filters F, X, a filter A and a map G from types to
filters:
  app F X   = { t | g <= x -> t for some g in F, x in X }
  lam A G   = { t | f <= t, EntS f (x -> v with x : A and v in G x) }
  pi A G    = { t | om <= t, or pi a b <= t with a in A and
                    EntS b (x -> v with x : A and v in G x) }
where x : A (TyIn) means x : a for some a in A: the paper's typing of
the compact element x by the domain element A.  These are filters:
 - app: om = g with x = om (om <= om -> om);  meets: g1 /\ g2 <=
   (x1 /\ x2) -> (t1 /\ t2);  up: arrows covariant in the codomain.
 - lam: om = f; meets: f1 /\ f2, the entries of a meet are those of the
   parts; up by definition.
 - pi: meets: pi (a1 /\ a2) (b1 /\ b2) <= pi a1 b1 /\ pi a2 b2.
Each entry carries its own witness a in A of x : A.  The paper's form
(one a with dom(f, a)) is recovered for typed terms, where the witnesses
have a common typed lower bound (Lemma 3.9); with one witness the meet of
two elements would need that lower bound, so lam A G would be a filter
only for typed A.  lam and pi need no typing to be filters.

All three operations are monotone: F c= F', X c= X' give
app F X c= app F' X'; A c= A' and G x c= G' x for all x : A give
lam A G c= lam A' G' and pi A G c= pi A' G'.

Lemma 3.1 (selection).  Let G be antitone (x' <= x gives G x c= G x'),
EntS f R with R x v => v in G x.  For an arrow selection d, t of f and
x0 <= d: t in G x0.
Proof.  Induction on the selection.  Empty: t = om.  One entry x -> v:
v in G x c= G x0 as x0 <= d = x.  A component of a meet: inversion of
EntS.  Meet of selections: x0 <= d1, d2, induction, meet.

Lemma 3.2 (consistency of entries).  If moreover R x v gives Cons x, and
every element of G x is consistent when Cons x, then Cons f.
Proof.  By Lemma 1.2 (cons-fix) it suffices to check the clauses.  f has
no U or Pi component: (c1)-(c3) are vacuous and its pi selections are
om-only (c4).  (c5): for an arrow selection d, t with Cons d, t is in
G d by 3.1 (x0 = d), hence consistent.

Lemma 3.3.  If every entry x -> v with R x v and f0 <= x -> v has
x -> v in a filter X, then f0 in X for EntS R f0.  (Induction on EntS,
f0 <= f1 /\ f2 giving f0 <= f1 and f0 <= f2.)

3.3 Semantics of terms (paper Fig. 4, left, with domain environments)

An environment rho on n variables maps each variable to a filter (the
paper's EnvD, Def. 2.28; a compact environment is the case of principal
filters).  (rho, X) extends rho by X.
  [[var i]] rho = rho i          [[U]] rho = univF
  [[Pi A B]] rho  = pi  ([[A]] rho) (x |-> [[B]] (rho, prin x))
  [[lam A M]] rho = lam ([[A]] rho) (x |-> [[M]] (rho, prin x))
  [[app M N]] rho = app ([[M]] rho) ([[N]] rho)
by recursion on the term.  The family x |-> [[B]] (rho, prin x) is
antitone in x by 3.4 (prin is antitone).

Lemma 3.4 (monotone).  rho i c= rho' i for all i gives
[[M]] rho c= [[M]] rho'.  So [[M]] respects pointwise equivalence.
Proof.  Induction on M, the operations being monotone.

Lemma 3.5 (consistency).  If every element of every rho i is consistent,
so is every element of [[M]] rho.
Proof.  Induction on M.  var: hypothesis.  U: Cons U and 1.3.  app:
g <= x -> t with Cons g, Cons x gives Cons t (Typing.cons-value).
lam, pi: Lemma 3.2 with the induction hypothesis at (rho, prin x), whose
elements are consistent when Cons x; for pi also Lemma 1.4.

Lemma 3.6 (continuity).  t in [[M]] rho gives compact k with k i in
rho i for all i and t in [[M]] (prin . k).
Proof.  Induction on M.  Approximations compose by meets: if k1 and k2
are approximations, so is k1 /\ k2 (pointwise; filters are closed under
meets), and a property monotone in k holding at k1 holds at k1 /\ k2
(3.4).  var i: the point environment, t at i and om elsewhere.  U: om
everywhere.  app: the meet of the two approximations.  lam, pi: the
witness a in [[A]] rho, and for each entry x -> v the approximation of
v in [[M]] (rho, prin x), restricted to the old variables (its value at
the new variable is below x, so prin x is replaced by a smaller filter,
3.4); the meet of all these, by induction on EntS.

Lemma 3.7 (traversal, paper Lemma 2.29).  For a kit with the two laws
  [[var vz]] (rho, X) == X,     [[var (wk v)]] (rho, X) == [[var v]] rho,
[[trav s M]] rho == [[M]] (i |-> [[var (s i)]] rho).
Proof.  Induction on M.  Under a binder the environment
i |-> [[var (lift s i)]] (rho, prin x) is pointwise equivalent to
(i |-> [[var (s i)]] rho, prin x) by the two laws; then 3.4.
The renaming kit satisfies both laws by definition; so (instance)
[[wk M]] (rho, X) == [[M]] rho.  The substitution kit satisfies the first
by definition and the second by this instance.  Instance:
[[M[N]]] rho == [[M]] (rho, [[N]] rho).

3.4 Semantic typing of filters (paper section 2.2, end)

A : B  (HasTy) for filters: every t in A is below a typed element of A:
some v <= t with v in A, v : c for some c in B.  Typed elements are not
closed downward (step 2), so this is the right notion: t itself need not
be typed.  An environment rho fits G (Def. 2.30) when for each variable
x : A of G, [[A]] rho : univF and rho x : [[A]] rho.  Fitting gives
consistent environments (2.4 and 1.3).

Lemma 3.8.  v : c and U <= c give v : U.  (Generation: c is om-like or U.)
So A : univF gives, for t in A, a <= t in A with a : U.

Lemma 3.9 (a common domain).  EntS f (x -> v with x : A and Q x v) gives
a in A such that x : a' for every entry and every a' <= a with a' : U.
Proof.  Induction on EntS: om; the witness of the entry and Prop. 2.5;
the meet of the two witnesses.  With A : univF take a' <= a, a' : U
(3.8): all keys are of type a'.

3.5 Theorem 2.31 (soundness).  If rho fits G:
  G |- M : A       gives  [[M]] rho : [[A]] rho;
  G |- M = N : A   gives  [[M]] rho == [[N]] rho.
Proof.  Induction on the derivation (one eliminator for the family).
In the binder cases (rho, prin x) fits G, x : A when [[A]] rho : univF
and x : [[A]] rho (prin x : [[A]] rho as x is typed).

var: rho i : [[A]] rho' with [[wk A]] == [[A]] (3.7), by induction on
  the context.
U: t in univF: U <= t, U : U.
Pi: om <= t: t : om.  pi a b <= t: by 3.9 a' <= a in [[A]] with a' : U
  and every key of b of type a'; each value v in [[B]] (rho, prin x) is
  above a typed v' : U in it (induction hypothesis and 3.8).  b' = the
  entries x -> v'.  Then pi a' b' <= t, pi a' b' in [[Pi A B]] rho,
  Cons b' (3.2), so pi a' b' : U (rule Pi).
lam: f <= t.  a' as for Pi.  Each value v in [[M]] (rho, prin x) is above
  v' : c, c in [[B]] (rho, prin x), and c above y : U in it; v' : y
  (2.5).  f' = the entries x -> v', phi' = the entries x -> y.  Then
  f' <= f <= t, f' in [[lam A M]] rho, phi' in [[lam A B]] rho, Cons f',
  Cons phi' (3.2), ent f' a' phi', ent phi' a' (om -> U), so
  Pi(a', phi') : U and f' : Pi(a', phi'), and pi a' phi' is in
  [[Pi A B]] rho.
app: g <= x -> t, g in [[M]] rho, x in [[N]] rho.  Typed elements
  g' <= g, g' : c, c in [[Pi A B]] rho, and x' <= x, x' : a, a in [[A]]
  rho.  Generation of g' : c:
   - g' om-like: t om-like (Typing.app-bot), t : om.
   - c == U: against c in [[Pi A B]] rho (no confusion).
   - c == Pi(A1, phi1), g' == a lambda: pi a0 b <= c for some a0 in
     [[A]] rho and entries b, so A1 is in [[A]] rho and b <= phi1.  Let
     A2 <= A1 /\ a, A2 in [[A]] rho, A2 : U (3.8).  Then x' : A2 and
     g' : Pi(A2, phi1) (2.5).  g' <= x' -> t gives a selection d, t'' of
     g' with x' <= d, t'' <= t; Lemma 2.8 (extended: g' <= x' -> w)
     gives w <= t'', w : y with phi1 <= x' -> y.  w is in
     [[app M N]] rho (g', x'), and y in [[B]] (rho, prin x') by 3.1 on
     the selection of b given by b <= phi1 <= x' -> y, hence in
     [[B]] (rho, [[N]] rho) == [[B[N]]] rho (3.4, 3.7).
conv (typing): [[A]] rho == [[B]] rho.
refl, sym, trans, conv: immediate.
Pi-congruence, application congruences: the operations are monotone;
  for Pi only at x : [[A]] rho, where (rho, prin x) fits.
beta: [[app (lam A M) N]] rho == [[M[N]]] rho.
  c=: g <= x -> t with f <= g, EntS f: the selection of f below x -> t
   and 3.1 give t in [[M]] (rho, prin x) c= [[M]] (rho, [[N]] rho).
  =c: t in [[M]] (rho, [[N]] rho): by continuity (3.6) t is in
   [[M]] (rho, prin x) for some x in [[N]] rho; x' <= x typed in
   [[N]] rho, of type a in [[A]] rho; the single entry x' -> t is in
   [[lam A M]] rho, and x' -> t <= x' -> t.  Here "below a typed
   element" is used: x itself need not be typed.
eta: [[f]] rho c= [[g]] rho (and symmetrically).  t in [[f]] rho is above
  t' : c in [[f]] rho, c in [[Pi A B]] rho.  t' om-like: t in [[g]] rho.
  c == U: excluded.  c == Pi(A1, phi1), t' == f0 with ent f0 A1 phi1:
  A1 in [[A]] rho.  By 3.3 it suffices that every entry x -> v of f0
  with f0 <= x -> v is in [[g]] rho.  x : [[A]] rho, so (rho, prin x)
  fits; v is in [[app (wk f) (var 0)]] (rho, prin x) (f0 in
  [[wk f]] (rho, prin x) by 3.7, x in prin x); by the induction
  hypothesis v is in [[app (wk g) (var 0)]] (rho, prin x): g1 <= x1 -> v,
  g1 in [[g]] rho, x <= x1, so x -> v is in [[g]] rho.
The coalesced sum (om <= om -> om) is used in app (the om element) and
in lam (om is a function).

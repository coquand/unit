Chatelet's theorem and descent of finite freeness
================================================

This development proves Chatelet's theorem for the topology generated by
mere roots of monic polynomials of positive degree. Its inputs are the SAG
axioms (Loc, SQC, Zariski-local choice) and propositional sheafification
with lexness. Descent of finite freeness and of split bases is proved here.

The algebraic equivalence between finite projectivity and finite
presentation plus flatness is also proved, over an arbitrary commutative
ring, without the SAG axioms.

Check from the repository root:

    cabal build
    timeout 120 ./segc sag/chatelet all
    ./segc sag/chatelet changed

Checked with Unit's own checker: 393 modules, 0 failed, 10.92 s.
Both mathematical documents rebuild without LaTeX warnings.

The main entry points are:

- ChateletEtaleDescent.Over[R,setR,sag,sh].At[n0].chatelet
  Chatelet's theorem with no descent parameter.
- DescentTheoremD.Over[R,setR,sag,sh].At[M,modal,rank,local].theorem
  A sheaf module locally free of a fixed rank merely has a basis.
- DescentFree.Over[R,setR,sag,sh].Rank[n].At[A,modal,S,local].descends-free
  A local split basis descends when the ambient module is finite free.
- DescentProjective.Over[R,setR].At[M].finite-projective-iff-fp-flat
  A module is finite projective iff it is finitely presented and flat.

Flatness in DescentFlat is the single-relation criterion. OneToMany
proves its extension to finite systems. Presentation in DescentProjective
is a finite exact presentation; Retract is a retract of a finite free
module. This equivalence does not itself assert faithfully flat descent.

Mathematical proofs, with LaTeX sources beside them:

    ../../doc/chatelet-descent.pdf
    ../../doc/finite-projective-flat.pdf

The descent proof first establishes that weak quasi-coherence descends for
a module with a sheaf carrier (DescentQC). Fractions can then be cleared
(DescentFractions), functions on a root scheme expanded in a finite power
basis (DescentEvaluation), and membership in a finite span descended
(DescentSpan). DescentGenerators constructs finitely many generators;
DescentBasis selects a basis using openness. DescentLeftInverse descends
the retraction by solving its rows as finite linear systems.

Theorem342.OverAzumaya uses descent only for algebras locally equal to the
matrix algebra. The older Theorem342.Over and ChateletEtale interfaces are
kept for compatibility.

Sources and dependencies
------------------------

The complete import tree is included. Identical existing Unit modules are
reused through relative links; all other prerequisites are source files
in this directory. No link points outside this repository. The checker
and the existing developments are unchanged.

Chatelet and the classification of line bundles. The two mathematical

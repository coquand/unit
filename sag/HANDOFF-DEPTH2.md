## Setting and representation choices

- Ring `Rg : Ring[l].CRing` with `setR`, modules `E : Modules.Over.Module`
  (an `Alg73.Mod` over `RingBridge.ring`), as in koszul/.  Ring statements
  are the instance `E = Modules.Over.regular` (the ring as a module), so
  there is one notion, not a ring copy and a module copy.
- A finitely generated ideal is a family `s : X -> R` over an index type X
  (as `cffr/RegularIdeal`, `cffr/Lemma84.GrTwo`), not an ideal predicate.
- Depth, explicit form (cffr §6 items 1–2; `koszul/GradeOne`, `GradeTwo`
  prove these equal to the Koszul grade for X = Fin N):
  - `Reg E X s`: s_i x = 0 for all i gives x = 0 (Gr(s; E) >= 1);
  - `Depth2 E X s`: Reg, and every family y : X -> E proportional to s
    (s_i y_j = s_j y_i) is merely s e (Gr(s; E) >= 2).
- Localisation is elementwise, no localised rings or modules: "x = y / s^k
  in E[1/s]" is "merely N with s^N (s^k x - y) = 0" (`Modules.Fractions`
  style).  This is the reading of the book's statements for monoids
  generated by one element s_i, which is all that 7.1, 7.4, 7.5 and the
  depth-2 case of 7.2 use.  General monoids S_i: not treated (record).
- Powers: `Alg73.RA.pw` (Base.Nat).
- Minors (Sharpe): U is given by its n columns u_j in R^m (`exterior/`
  matrices are lists of columns).  For a list of rows rho : Fin n -> Fin m,
  U_rho : Mat n, delta_rho = det U_rho.  The family of n-minors is indexed
  by all row lists (repetitions and every order): it generates D_n(U), as a
  repeated row gives 0 and a permutation a sign.  The (n+1)-minors of
  W = [U | V] for sigma : Fin (n+1) -> Fin m are expanded along the V
  column (cofactors c_sigma(t) = det [u o sigma, e_t] times V_sigma(t)); for
  V in R^m this is det W_sigma (column linearity, `Adjugate.form-expand`).

## Plan, in order

1. `Depth`: Reg, Proportional, Depth2 for a module; Depth2 is a
   proposition; the multiple e is unique (no truncation needed once Reg);
   invariance under reindexing by a bijection.
2. `DepthPowers`: (product) Depth2 (t, a) and Depth2 (t, b) give
   Depth2 (t, ab), for families on Z + Top; powers at the last index;
   Depth2 s gives Depth2 (s_i^(e_i)) for s on Fin n (induction on n with an
   extra fixed block Y: families on Fin n + Y; reassociation by reindexing).
3. `Divisibility` (7.1): y regular, Gr(s) >= 2, y | x locally (s_i^(e_i) x =
   y c_i) gives y | x; strong gcd local-global, with "y regular in A[1/s]"
   and "y | w in A[1/s]" read elementwise.
4. `Gluing` (7.4): compatible fractions y_i / s_i^(k_i) (compatibility on
   overlaps elementwise) come from a unique x in E, when Gr(s; E) >= 2.
   Proof: normalise the exponents (one K), choose the overlap exponents
   (finite choice; the goal is a proposition), take a common M, then the
   families (s_i^M y_i) and (s_i^(K+M)) are proportional, Depth2 of powers.
5. Sharpe (7.5), ring case F = A first:
   - `Cofactor`: det A^T[k <- e_i] = det A[i <- e_k] (both are det Z, Z = A
     with column i and row k cleared: A[i <- e_k] E = Z, E elementary,
     `WiebeMatrices.emat`/`det-emat`; for A^T the same lemma gives Z^T,
     `det-transpose`); hence A adj(A) = det A . I, and Cramer existence
     B (adj B a) = det B . a (`DeterminantTrick.act-mmul`).
   - `SharpeRows`: for sigma = (rho, r): c_sigma(last) = delta_rho
     (`WiebeMatrices.BlockDet`), c_sigma(p) = - sum_k U_rk det U_rho[k <- e_p]
     (Cramer existence on N' = [u o sigma, e_last], last coordinate, and
     BlockDet for each column replacement).  So D_{n+1}(W) = 0 gives
     delta_rho V_r = sum_k U_rk X_rho,k, X_rho = adj(U_rho) V_rho, all r.
   - `Sharpe`: uniqueness (U z = 0 and Gr(D_n U) >= 1 give z = 0, by
     adj(U_rho) U_rho = delta_rho I); proportionality delta_rho' X_rho =
     delta_rho X_rho' (uniqueness applied to their difference); Depth2 gives
     x with X_rho = delta_rho x; then U x = V by Reg.  Also the converse
     (a solution forces D_{n+1}(W) = 0).
6. `LocalDepth` (7.2 for k = 2, then 7.3): Gr(a; E[1/s_i]) >= 2 for each i
   (elementwise) and Gr(s; E) >= 2 give Gr(a; E) >= 2: local multiples are
   unique, so compatible, and glue by 7.4.
7. Sharpe with unknowns in a module F (needs finite sums in a module), then
   7.2 for general k and 7.6 if time.

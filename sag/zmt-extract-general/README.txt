Generic corrected-section extraction
====================================

All sources are new. Earlier/shared sources and the checker are unchanged;
dependencies are relative links. The construction uses generic Fin n natural
and Laurent exponents with n=suc m, newest coordinate Z=inr tt, affine
coordinates inl i. Pair orientation is newest first, hence
  d(z)_{Z,X_i}=z_{X_i}-z_Z.

Inputs are commutative set-rings A,E, a ring map A->E, finitely many y_i in E,
an ideal generated by b_j in A, arbitrary homogeneous term lists P_q of
nonnegative degrees e_q, and proved dehomogenization P_q(y,Z=1)=0. The actual
GenericReesChart image quotient is used throughout, without quotient models
or conditional complex records.

PrescribedPolynomialization constructs an element of the actual iterated
polynomial ring for any finite Laurent function f and prescribed natural
shift L, assuming the proved fact f(v-L) vanishes at negative exponents.
Its full Laurent coefficient function is f(v-L), not only its values at
natural exponent vectors. It proves shifted homogeneity as well.

ExtractionCoefficientLaws and ExtractionRingLaws compare finite term lists
and actual ring products/sums with Laurent coefficients and evaluation.
GenericDehomCoefficientExt (root helper) constructs evaluation of the actual
tower at Z=1 and X_i=y_i. Thus coefficient equality implies evaluation
equality over arbitrary bases. ExtractionPolynomials provides homogeneous
term representatives under truncation, using the existing tower bridge.

GenericExtractionInput packages the actual corrected-section equations:
  z,z0 actual generic rank1 twist(-1) cochains;
  z0_Z is the precise inverse-Z monomial;
  closed: explicit original-P image witness for d(z);
  reduction: explicit I+J witness for z-z0.
It derives pointwise J equations and the finite ideal-generator sum without
assuming further exactness, finite support, or polynomial representatives.

The MAIN checked export is
  GenericClearedExtraction.Over[A,E,setA,setE,iota,m,y,t,b,s,p,e,hp,dehP]
    .Sec[z,z0,hz0].Witness[closed,reduction]
    .Support[S,sz,sy,sx,sy'].extracted
      : Trunc[GenericDegreeLoweringData.Over[same algebra data].Data].

S is one finite list containing the actual cochain supports: z, the closed
J multipliers, the reduction I coefficients, and the reduction J multipliers.
ExtractionCommonSupport proves the required inclusions when combining these
four families. The outer theorem GenericSectionExtraction in zmt-general
eliminates these support and input witness truncations using finite choices.

For finite support S, the independent ExtractionBounds helper increases each
negative-coordinate bound by1. On chart Z use LZ=(B_Z+1)e_Z; on chart X_i use
Li=(B_i+1)e_i; on their overlap use the same LE=LZ+Li. All clearings are proved
by finite bounds plus actual chart vanishing. The section polynomial has
degree B_Z; the ith polynomial has degree B_i. Actual coefficient equality
on each edge proves, after evaluation,
  s*y_i^(B_i+1)=q_i(y).
The Z chart and exact inverse-Z normalization prove
  s=1+sum_j iota(b_j)*v_j.

Crucial simplification: auxiliary J and I multipliers remain elements of
the polynomial ring, evaluated directly by its constructed ring map. No
term-list representative is chosen for them. Only sT and the finite family
q_i need homogeneous representatives; those choices are finite and remain
under truncation. There is no infinite sequence choice or new axiom.

The output is EXACT GenericDegreeLoweringData (from the separate certificate
track), so GenericDegreeLoweringCertificate.certificate applies directly.
Coherence/Noetherian/CFN hypotheses are absent from extraction itself; they
enter only in the earlier constructed correction step.

GenericExtractionRegression checks actual empty-affine extraction (one Z
chart, no pair charts) over every set-ring, and the five-coordinate composed
correction-to-data theorem for arbitrary four-variable residual inputs.
The latter supplies every correction input internally. Root's final full
ZMT regressions cover the subsequent certificate/export/descent integration.

opening audits, and isolated deliberate mutations. No commits were made.

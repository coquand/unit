Basic standard charts without integrality (sag/etale-basic-local)
==================================================================

1. Statement

  ShortBasicEtale.Over[R,setR,cs].At[E,y,full,unique]
    .theorem      fp smooth
    .flat-theorem fp flat

R: any commutative set-ring.  E: an R-algebra, merely finitely presented
(fp), formally unramified (unique), and formally smooth (smooth) or
R-flat (flat).  y in E, G = include cs in R[T], and
  full: every e in E is merely A(y)/G(y)^n (PolynomialFractions.At.Full).

Output, merely: the localisation E[1/G(y)] with its universal property,
H and D in R[T], and StandardEtale.Points[H,D].Standard for it:
  E[1/G(y)] = (R[T]/(H))[1/D],   D = G F H'.

Compared with sag/etale-monic-local (ShortLocalEtale) the hypothesis
"y is integral" is removed and H is an arbitrary polynomial, not monic.
G(y) need not be a unit and y need not be integral.

2. Proof

  BasicStandard (G(y) a unit):
   (1) MonogenicDerivativeIdeal + SimplePolynomialRelation give H with
       H(y) = 0 and H'(y) = G(y)^N.  These two steps never used
       integrality; only the monic step MonicRelation did, and it is
       not used here.
   (2) StandardAlgebra.Build constructs S = (R[T]/(H))[1/(G H')] for
       any H; y is a point of (H, G), so S -> E, surjective by full.
   (3) FiniteSurjectionKernel + EtaleCase: the kernel is generated by an
       idempotent, so E = (R[T]/(H))[1/(G F H')].
  LocalBasicStandard: T = E[1/G(y)] via PrincipalEtale (presented,
   unramified, smooth); every element of T is a fraction over G(y);
   apply BasicStandard to T.
  ShortBasicEtale: eliminate the truncated presentation; the flat
   variant gets smoothness from FlatUnramifiedEtale (sag/etale-direct).

The three files are MonogenicStandard, LocalMonogenicStandard and
ShortLocalEtale with the integral equation removed; no other change.

3. Use

This is step 2-3 of the two-variable route: for
E = (R[X,Y]/(F,G))[1/Delta] and a relation U F + V G = a(Y) X + b(Y),
the chart E[1/a(y)] is generated by y with fractions (x = -b(y)/a(y),
1/Delta = a(y)^(k+1)/(a D)(y)), so it is basic standard.  Not done here:
the fraction computation for that E, the adjugate construction of a, b,
the one-equation theorem (monic charts from basic ones), and the cover.

4. Regressions (BasicLocalRegression)

  Point[R,a,t]: the base algebra, y = a, G = t, through all three
   endpoints; instances over Z/4Z with t = 1, t = 2 (nilpotent: the
   localisation is 0), t = 0, a redundant presentation and the empty
   presentation.
  StandardInput.Given: any standard algebra (R[T]/(Q))[1/(aux Q')] with
   Q arbitrary (e.g. tT - 1, presenting R[1/t] by a non-integral
   generator) at its own generator, through BasicStandard.
